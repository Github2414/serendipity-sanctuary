# Serendipity Sanctuary 🌿
A progressive web application functioning as a comprehensive toolkit for mental health management and positive peer interactions. This project integrates journaling, emotional analytics, and crisis management into a unified, secure workflow.

## 🛠️ Tech Stack
- **Backend:** Python, Flask, Werkzeug.
- **AI & NLP:** VADER Sentiment (lexicon and rule-based sentiment analysis).
- **Frontend:** HTML5, CSS3 (3D Glassmorphism UI), JavaScript (ES6).
- **Data Visualization:** Chart.js.
- **Database & Architecture:** Localized JSON file architecture and JavaScript Fetch API for asynchronous HTTP requests.

## 🚀 Technical Highlights & Key Features

### 🧠 Dual-Mode Moderation & AI CBT Reframer
Combines fast algorithmic keyword blocking (toxicity filter) with deep, context-aware VADER sentiment classification. If a user's input drops below healthy emotional thresholds, the system delivers immediate cognitive behavioral reframing and automated AI "System Interventions".

### ⚡ Asynchronous UI & Responsive Community Feed
Intensive Python backend NLP operations are handled via asynchronous JavaScript fetches, ensuring the user interface remains completely responsive without freezing during text analysis. It includes kinetic keystroke monitoring and customizable UI themes like 'Digital Sunset' to filter blue light.

### 📊 Wellness Insights & Visual Analytics
Integrated dynamic Chart.js canvases validate mood patterns visually, generating real-time, dual-dashboard visualizations of Community Pulse versus Personal Reflection.

### 🔒 Encrypted Private Journal & Time-Capsules
Features a localized, encrypted daily text diary managed via custom CRUD operations that never touches the public feed. Includes an "Echo of Hope" tool where users schedule time-capsule messages for their future selves.

### 🔥 The Void (Cathartic Text Destruction)
A "type and burn" non-destructive module where users type out anger or anxiety. The data is immediately auto-deleted locally without ever being sent to a server or saved.

### 🛟 Chain of Support (SOS) & Grounding Tools
A dedicated crisis management module that maintains a trusted SOS contact list and guides users through a structured 5-4-3-2-1 psychological grounding exercise.
